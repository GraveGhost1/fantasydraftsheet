Underdog Draft Assistant

A Chrome overlay for Underdog Best Ball. It uses the same rankings as your draft sheet and does not change the existing board.

Your server URL

Paste this into the extension popup as Draft Sheet URL.

Local: keep http://127.0.0.1:8000 and run python app.py.

Install the Chrome extension

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked
  4. Select the extension folder in this project
  5. Pin Draft Sheet Assistant, log in (or use public ranks), then open an Underdog draft

Try it without a live draft

After the extension is loaded, open the local test room:

Open test draft room

Take My pick to fill your roster and the capital bars. Top remaining names turn green, then orange, then red. In the overlay, cycle QB/RB/WR/TE between dock, boost, and exclude.

On Underdog

  1. Join a Best Ball draft on underdogfantasy.com
  2. The panel appears on the right and re-ranks remaining players as picks come off
  3. You still make the pick in Underdog — this overlay does not auto-draft

Back to the draft sheet · existing rankings, login, and Sleeper sync are unchanged.
