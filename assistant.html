Draft Assistant

A Chrome overlay for Underdog and DraftKings Best Ball. It uses the same Ghost FF ranks and does not change the draft board.

Your server URL

Paste this into the extension popup as Ghost FF URL.

Local: keep http://127.0.0.1:8000 and run python app.py.

Install the Chrome extension

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked
  4. Select the extension folder in this project
  5. Pin Ghost FF Assistant, log in (or use public ranks), then open a draft

Try it without a live draft

After the extension is loaded, open the local test room:

Open test draft room

Take My pick to fill your roster and the capital bars. Top remaining names turn steel, then orange, then red. In the overlay, cycle QB/RB/WR/TE between dock, boost, and exclude.

On Underdog

  1. Join a Best Ball draft on underdogfantasy.com
  2. The panel appears on the right and re-ranks remaining players as picks come off
  3. You still make the pick in Underdog — this overlay does not auto-draft
